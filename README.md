# Tic-Tac-Toe Practice Project

This is a simple beginner-friendly Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

It was created as a practice project while learning front-end web development, especially DOM manipulation, event listeners, and basic game logic.

## Overview

The game allows two players to take turns placing `X` and `O` on a 3x3 grid. It checks for a winner, shows the result in a message box, and lets the player start a new round or reset the board.

## Features

- Two-player gameplay
- Turn-based logic for `X` and `O`
- Win detection on rows, columns, and diagonals
- Message popup for the winner
- Reset and new game buttons
- Simple responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project folder.
2. Go to the `tic_tac_toe` folder.
3. Open `index.html` in your browser.

You can also run a local server from the project root if you prefer:

```bash
cd "C:\Users\Akshat\WEB DEV NEW\Tic-Tac-Toe"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/tic_tac_toe/index.html
```
